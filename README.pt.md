<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Gestura/raw/main/public/favicon/favicon.svg" width="40"/> Gestura</h1>

<p align="center">
   Gestura é uma plataforma de análise facial em tempo real que utiliza visão computacional para detectar expressões, pontos de referência faciais, idade e gênero.
</p>

![GesturaDemo](https://github.com/KrishBharadwaj5678/Gestura/raw/main/assets/demos/Gestura.png)

<img src="https://github.com/KrishBharadwaj5678/Gestura/raw/main/assets/readme/divider.gif" width="100%"/>

## <img src="https://github.com/KrishBharadwaj5678/Gestura/raw/main/assets/readme/features.gif" width="35"/> Recursos

| Recurso | Descrição |
| ------- | --------- |
| 🤖 Detecção de Gestos Faciais | Analisa expressões e movimentos faciais em tempo real |
| 📌 Identificação de Pontos Faciais | Detecta pontos-chave do rosto para uma análise precisa |
| 🎯 Estimativa de Idade | Estima a idade utilizando análise facial baseada em IA |
| 👤 Detecção de Gênero | Estima o gênero utilizando algoritmos avançados de visão computacional |

## <img src="https://github.com/KrishBharadwaj5678/Gestura/raw/main/assets/readme/gettingStarted.gif" width="35"/> Como Começar

### 1️⃣ Clonar o Repositório

```bash
git clone https://github.com/KrishBharadwaj5678/Gestura.git
````

### 2️⃣ Acessar o Diretório do Projeto

```bash
cd Gestura
```

### 3️⃣ Instalar as Dependências

```bash
npm install
```

### 4️⃣ Iniciar o Servidor de Desenvolvimento

```bash
npm start
```

### 5️⃣ Abrir no Navegador

Abra o seguinte endereço no navegador:

`http://localhost:5000`
