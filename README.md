<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Gestura/raw/main/public/favicon/favicon.svg" width="40"/> Gestura</h1>

<p align="center">
   Gestura is a real-time facial analysis platform that detects expressions, facial landmarks, age, and gender using computer vision.
</p>

![GesturaDemo](https://github.com/KrishBharadwaj5678/Gestura/raw/main/assets/demos/Gestura.png)

## <img src="https://github.com/KrishBharadwaj5678/Gestura/raw/main/assets/readme/features.gif" width="35"/> Features

| Feature                    | Description                                      |
| -------------------------- | ------------------------------------------------ |
| 🎭 Face Gesture Detection  | Analyze facial expressions and movements in real time |
| 📌 Landmark Identification | Detect key facial landmarks for precise analysis |
| 🎯 Age Estimation          | Estimate age using AI-powered facial analysis   |
| 🧑 Gender Detection        | Identify gender using advanced computer vision |

## <img src="https://github.com/KrishBharadwaj5678/Gestura/raw/main/assets/readme/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/KrishBharadwaj5678/Gestura.git
```

### 2️⃣ Navigate to the project directory
   
```bash
cd Gestura
```

### 3️⃣ Install dependencies

```bash
npm install
```

### 4️⃣ Start the development server
   
```bash
npm start
```

### 5️⃣ Open your browser

Navigate to `http://localhost:5000`
