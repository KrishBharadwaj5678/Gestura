<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Gestura/raw/main/public/favicon/favicon.svg" width="40"/> Gestura</h1>

<p align="center">
   Gestura это платформа для анализа лица в реальном времени, которая с помощью компьютерного зрения определяет выражения лица, лицевые ориентиры, возраст и пол.
</p>

## <img src="https://github.com/KrishBharadwaj5678/Gestura/raw/main/assets/readme/features.gif" width="35"/> Возможности

| Возможность                  | Описание                                           |
| ---------------------------- | -------------------------------------------------- |
| 🤖 Распознавание жестов лица | Анализ выражений и движений лица в реальном времени |
| 📌 Определение ориентиров    | Обнаружение ключевых точек лица для точного анализа |
| 🎯 Оценка возраста           | Определение примерного возраста с помощью ИИ      |
| 👤 Определение пола          | Определение пола с использованием компьютерного зрения |

## <img src="https://github.com/KrishBharadwaj5678/Gestura/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/Gestura.git
````

### 2️⃣ Переход в директорию проекта

```bash
cd Gestura
```

### 3️⃣ Установка зависимостей

```bash
npm install
```

### 4️⃣ Запуск сервера разработки

```bash
npm start
```

### 5️⃣ Открытие в браузере

Откройте в браузере:

`http://localhost:5000`
