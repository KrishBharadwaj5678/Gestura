<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/Gestura/raw/main/public/favicon/favicon.svg" width="40"/> Gestura</h1>

<p align="center">
   Gesturaは、コンピュータービジョンを活用して、表情、顔のランドマーク、年齢、性別をリアルタイムで検出する顔分析プラットフォームです。
</p>

## <img src="https://github.com/KrishBharadwaj5678/Gestura/raw/main/assets/readme/features.gif" width="35"/> 機能

| 機能 | 説明 |
| ---- | ---- |
| 🤖 顔ジェスチャー検出 | 表情や顔の動きをリアルタイムで分析 |
| 📌 ランドマーク検出 | 詳細な分析のために顔の主要な特徴点を検出 |
| 🎯 年齢推定 | AIを活用して推定年齢を分析 |
| 👤 性別検出 | 高度なコンピュータービジョン技術を使用して性別を推定 |

## <img src="https://github.com/KrishBharadwaj5678/Gestura/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローン

```bash
git clone https://github.com/KrishBharadwaj5678/Gestura.git
````

### 2️⃣ プロジェクトディレクトリへ移動

```bash
cd Gestura
```

### 3️⃣ 依存関係をインストール

```bash
npm install
```

### 4️⃣ 開発サーバーを起動

```bash
npm start
```

### 5️⃣ ブラウザで開く

ブラウザで以下のURLにアクセスしてください。

`http://localhost:5000`
